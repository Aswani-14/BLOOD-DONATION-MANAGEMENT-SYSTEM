# 🩸 Blood Donation Management System

A Java Swing and MySQL based desktop application developed for managing blood donation camps, donors, volunteers, organizations, blood stock, and blood requests efficiently.

---

## 📌 Features

- Secure Login System
- Admin Dashboard
- Camp Management
- Donor Management
- Volunteer Management
- Blood Stock Management
- Organization Management
- Blood Request System
- Request Approval/Rejection
- Camp-wise Report Generation

---

## 🛠 Technologies Used

- Java
- Java Swing
- JDBC
- MySQL
- IntelliJ IDEA

---

## 🧩 Modules

### Admin Modules
- Camp Management
- Donor Management
- Volunteer Management
- Blood Stock Management
- Organization Management
- Request Management
- Report Generation

### Organization Module
- Login
- Submit Blood Request
- View Request Status

---

## 🗄 Database

Database used: MySQL

Main Tables:
- login_table
- camp_table
- donor_table
- volunteer_table
- blood_stock_table
- organization_table
- request_form_table

---

## ▶️ How to Run

1. Clone the repository
2. Open project in IntelliJ IDEA
3. Import MySQL database
4. Configure JDBC connection
5. Run `LoginFrame.java`
